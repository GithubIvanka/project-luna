# `luna-common`

## Назначение

Набор небольших общих типов и идентификаторов, которые нужны нескольким компонентам Luna.

## Владеет

- идентификаторами Bundle, пользователя, сессии и версий;
- базовыми типами доступа;
- описанием `RuntimeSpec` и выбора libc;
- `RuntimeProfile`;
- другими фундаментальными value types.

## RuntimeSpec

`RuntimeSpec` описывает среду выполнения одного приложения. Для одного процесса выбирается одна libc:

```text
musl
или
glibc
```

`musl` используется для native Luna userspace; `glibc` — для совместимых приложений, которым она требуется.

`RuntimeProfile` описывает минимальный набор доверенных системных логических ресурсов и не выбирает libc.

## Ограничения

`luna-common` не содержит операций файловой системы, security policy, runtime state, хранилище конфигурации, IPC transport или lifecycle процессов.

Общие типы должны оставаться маленькими и не превращать crate в место для логики всех подсистем.

## Зависимости

Базовые типы по возможности не зависят от более высоких domain components.

## Статус

Основные типы значений и модели runtime/profile реализованы.
