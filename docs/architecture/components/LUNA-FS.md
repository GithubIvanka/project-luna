# `luna-fs`

## Назначение

Небольшая абстракция файловой системы для mapping и работы с ресурсами.

## Владеет

Моделью файловых дескрипторов и метаданных, filesystem trait и host filesystem backend для тестов и разработки.

## Не владеет

Выбором application mappings, security policy или общей storage policy системы.

## Зависимости

Только стандартная библиотека Rust в текущей реализации.

## Статус

Базовая абстракция и host backend существуют. Production-поставщики хранения находятся за пределами текущей ответственности crate.
