# Documentation Style Guide

## Language

All documentation is written in English.

---

## Markdown

Use ATX headings.

Example:

# Heading

## Section

### Subsection

---

## Line Length

Prefer lines shorter than 100 characters.

---

## Lists

Use unordered lists whenever possible.

---

## Code

Always specify the language.

Example:

```rust
fn main() {}
```

---

## RFCs

RFCs must follow the official Project Luna RFC template.

---

## Naming

Use lowercase file names whenever practical.

Example:

filesystem.md

packages.md

services.md
