## Почему claude-mem не работал

Плагин Codex 13.35.0 использовал общий порт 37700 с рабочим процессом версии
13.25.3 от Claude. У старого процесса не было новых API `mem_search`
и `work_state`, что вызывало ошибку поиска и HTTP 404. Одного перезапуска было
недостаточно: старый плагин Claude при запуске наблюдателя обнаруживал
несовпадение версий и заменял процесс 13.35.0 своей версией. Это подтверждено
журналом сервера.

Кроме того, старый запуск Chroma не закреплял совместимые зависимости:
предварительная загрузка завершалась ImportError из Pydantic. Запуск версии
13.35.0 закрепляет ChromaDB и Pydantic; после согласования версий Chroma
подключилась, а заполнение прежними данными завершилось.

## Graphify: первоначальная установка

Пользователь уточнил название: Graphify. Установлены официальный навык Codex
`/home/sibitti/.codex/skills/graphify/SKILL.md` и его `references/` из уже
имеющегося CLI 0.9.57. После установки навык доступен со следующего хода.
Описание инструмента: [исходный проект Graphify](https://github.com/Graphify-Labs/graphify).

Построен локальный граф синтаксического дерева 133 файлов кода из `components/`,
включая незакоммиченные изменения того этапа. Он не включает смысловое извлечение
семи документов, граф общения, весь `docs/` или извлечение зависимостей Cargo
workspace. Последняя возможность требует Cargo.toml в корне сканирования;
в выбранной папке `components/` его нет. Внешние LLM не вызывались:
0 входных и 0 выходных токенов.

После группировки: 2596 узлов, 6722 связи, 115 групп. Названия групп оставлены
техническими: `--no-label` исключает вызовы LLM. Запрос
`graphify query 'ApplicationManager'` из корня репозитория возвращает типаж,
`plan`, `verify` и места в исходниках; они сверены с настоящим
`components/system/luna-app-manager/src/lib.rs`.

Ссылка `graphify-out` в корне тогда указывала на
`target/luna-graphify-20261010/graphify-out`. Основные артефакты:

- `graph.html` — интерактивный граф.
- `graph.json` — граф для команд query/path/explain.
- `GRAPH_REPORT.md` — сгенерированный отчёт.
- `ast-extraction.json` — исходное извлечение до группировки.
- `GRAPH-HEALTH.txt` — диагностика исходного извлечения.

Исходная диагностика обнаружила 370 ссылок без найденной цели и 42 пары объектов
с несколькими типами отношений. При построении простого графа часть отношений
может объединяться. Граф полезен для навигации, но неполон: выводы проверяются
по исходникам и контрактам. Сгенерированный отчёт эту проверку не заменяет;
один HEAD не описывает снимок незакоммиченных исходников.

```bash

graphify cluster-only components --graph target/luna-graphify-20261010/graphify-out/graph.json --no-label
```
