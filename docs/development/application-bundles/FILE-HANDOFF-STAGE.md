## Область этапа

GUI Files получает проверенный каталог, пользователь выбирает обработчик.
Первый обработчик — существующий Terminal/Ghostty с BusyBox less для просмотра
текста только для чтения. Данные не идут в host xdg-open или произвольный
сессионный D-Bus. Обычный Terminal/fish сохраняется отдельным режимом.

Используются существующие App Manager, AppRuntime, System Runtime,
политика безопасности, отображения корня, пространства имён и cgroup.
[Контракт передачи файла](../../contracts/APPLICATION-LAUNCH-CONTRACT.md)
определяет роли, неизменяемый режим, права, доказательства и жизненный цикл.

## Уже проверено на этом этапе

Первый набор native musl тестов проходит, GUI компилируется на хосте.
Проверены байты имён, отказы по пути/типу/владельцу, обнаружение подмены,
проверка отправителя сообщения и закрытие переданных дескрипторов.
Режим просмотра проверяется отдельно от обычного запуска с HOME.
Независимый обзор архитектуры выполнен; реальную реализацию предстоит
просмотреть после окончательных правок.
