# Luna Alpha — интерактивный дизайн

Локальный прототип визуального языка Project Luna. Перенос в настоящую ОС
описан отдельно в [IMPLEMENTATION.md](IMPLEMENTATION.md). Три варианта обоев —
ночное небо (по умолчанию), иллюстративный и геометрический — используют один и тот же интерфейс,
положение окон и масштаб. Сам HTML-прототип не изменяет ОС и её конфигурацию;
перенос в настоящую Alpha описан в IMPLEMENTATION.md.

## Открыть

Откройте прототип в современном браузере через локальный HTTP-сервер.
Он нужен в том числе для загрузки фотографии камня в WebGL. Все шрифты — системные;
CSS, JavaScript, SVG и PNG находятся рядом, сетевых зависимостей нет.
Для просмотра через HTTP из этого каталога:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8765/`.

Внешняя панель «Концепт Alpha» выбирает экран и художественный вариант;
она не является частью интерфейса ОС. Восемь экранов: загрузка,
блокировка, вход, рабочий стол, приложения, быстрые настройки,
настройки и отдельный просмотр трёх колец.

Пример воспроизводимого кадра:

```text
http://127.0.0.1:8765/?screen=desktop&variant=illustrated&capture=1
```

`screen`: `boot`, `lock`, `login`, `desktop`, `apps`, `quick`, `settings`,
`rings`. `variant`: `night`, `illustrated`, `geometric`. `capture=1` замораживает
анимацию на фиксированном угле. Размер 1280×800 — основная проверка ноутбука;
меньше 850 px окна выстраиваются вертикально.

## Проверяемые действия

- Нажатие на замок либо Enter на блокировке открывает вход.
- Пустой пароль показывает ошибку; любой непустой пароль открывает рабочий стол.
- Панель открывает Files, Ghostty, меню и настройки. Закрытые окна можно вернуть.
- Нажатие на окно меняет рамку клавиатурного/указательного фокуса.
- В Files работают боковая навигация, выделение, двойное нажатие по папке;
  «Загрузки» показывает пустое состояние.
- Поиск приложений фильтрует список; Enter выбирает первый результат.
- Wi-Fi, Bluetooth, ночной свет и ползунки имеют локальное состояние.
- Настройки переключают разделы; выбор обоев обновляет художественный вариант.
- Escape закрывает меню, быстрые настройки и настройки; Tab проходит действия.
- Три кольца анимируются в загрузке и отдельном просмотре. На остальных экранах
  цикл анимации отсутствует, при скрытии вкладки остановлен; учтено
  `prefers-reduced-motion`.

## Граница имитации

Все данные примера имитированы: время, пользователь, пароль, папки, файлы,
хранилище, процент батареи, сеть, яркость, громкость и сведения об экране.
Они не читаются с компьютера. Вход не проверяет настоящую учётную запись.
Ghostty показывает неизменяемый текст примера fish; команды не выполняются.
Выбор Firefox/micro/Yazi сообщает о выборе приложения, но не запускает процесс.
Кнопка питания не выключает компьютер. Поиск внутри Files и второе/третье
рабочие пространства пока показывают подсказку. Переключение ночного света
меняет его состояние, но не накладывает цветовой фильтр на весь прототип.

Прототип проверяет композицию, действия, читаемость, форму символа и движение;
он не подтверждает работу Noctalia, niri, аппаратуры или загрузку образа.
Встроенный WebGL рисует три серые каменные ленты по `rings.jpg` с мягкой
неоднородной фактурой, светлыми фасками и тенями соседних колец. Руны
плавно переходят от почти незаметного серого в цвет камня к прежнему яркому бирюзовому свету с двумя слоями ореола.
Для каждой из 48 рун при каждом новом цикле независимо выбирается случайный
период от 5 до 10 секунд; начальные фазы также независимы. Косинусная волна обеспечивает плавный стык циклов.
Прозрачные штрихи не конкурируют за глубину. Форма, уменьшенные вдвое зазоры,
оси и периоды вращения 12/17/23 секунды сохранены.
Ночное небо видно и за кольцами на загрузке; в этом фоне нет персонажа,
полумесяца, гор или передней скалы. Пример: `?screen=boot&variant=night`.
Это художническая проекция, не физический симулятор пересечений твёрдых тел.
Статический SVG предназначен для маленького фирменного знака.

Иллюстрации созданы через встроенный ImageGen; исходные промпты и provenance
находятся в `assets/IMAGE-PROMPTS.md`. Точные правила оформления: `SPEC.md`.

## План и проверка

Рабочий план: изучить concept_2/3 и выводы аудита → создать два художественных
фона → реализовать единые экраны и кольца → проверить синтаксис и браузерные
сценарии → сохранить кадры.

`node --check app.js` и `node --check assets/rings.js` завершились успешно
(PASS). Основные сценарии проверены в Codex In-app Browser; сохранены
девять JPEG-кадров экранов. Протокол проверки:
`target/luna-design-20261013/browser/verification.json`.

Это интерактивный макет, а не production-реализация Luna; браузерная проверка
подтверждает поведение макета и не подтверждает загрузку ОС в QEMU.

## Исходная каменная фактура

`assets/stone-reference.png` — точная копия присланного пользователем файла
`docs/design/visual-concepts/структура камня для кольца.png`. PNG не обработана.
Рендерер накладывает её на все грани тремя проекциями и смешивает их по нормали
поверхности: текстура закреплена на камне и движется с кольцом. При затухании
руны становятся почти прозрачными, сохраняя фактуру камня под знаком.
