# Перенос оформления в Alpha

## План и границы

1. Сохранить текущие параллельные изменения; изучить загрузку, вход, providers и сборку.
2. Перенести фон, палитру и композицию входа в нативный renderer `luna-user-session`;
   сохранить AccountDirectory, настоящую проверку credentials и обработку ошибок.
3. Настроить закреплённую Noctalia 5.2.0 и niri, оформить настоящие Files и Ghostty.
4. Перенести геометрию колец в нативный renderer с независимыми случайными циклами
   48 рун; показывать его во время реальной подготовки системных служб.
   В UEFI использовать отдельный статический трёхкольцевой знак.
5. Подключить ресурсы через исходники сборщика и бандлов; собрать musl-компоненты,
   выполнить канонический двухслотовый прогон QEMU, проверить экраны и приложения.

## Актуальный контракт

Вход принадлежит `luna-user-session`: AccountDirectory → SessionUi → credentials.
Отдельного greetd/Noctalia Greeter нет. Старое упоминание Greeter в SPEC описывало
предложение прототипа; указание пользователя и LUNA-USER-SESSION имеют приоритет.
Анимация после ядра также находится внутри этой графической границы, её жизненным
циклом во время подготовки служб управляет `luna-system-runtime`. PID 1 остаётся
`luna-init`. После остановки загрузочной презентации DRM освобождается для входа,
затем для niri. Никаких фиктивных процентов или искусственной задержки загрузки.

Неизменяемые фон и фактура включаются в System Image `/resources/images/`.
Поставщики рабочего стола и начальная конфигурация пользователя включаются в DATA
каноническим сборщиком. Ghostty получает тему через payload настоящего бандла.
HTML/JavaScript служат образцом; имитации действий и данных не переносятся.

Нативные экраны снимаются через QMP в отдельном запуске с `virtio-vga`, рабочий
стол — штатным `niri msg action screenshot-screen` с `virtio-vga-gl`.
Это связано с недоступностью GL scanout для QMP; экспортёр кадров в ОС не добавлен.
Проверка использует удаляемый слой, отклоняет неверный пароль, входит через
существующую аутентификацию и выполняет команду в настоящем fish внутри Ghostty.
Снимки niri передаются через отдельный UART QEMU с контрольной суммой SHA256;
системные журналы остаются в первом UART. Разрешение на второй порт существует
только во временной проверочной накладке, в канонический образ оно не попадает.

Статический кадр UEFI воспроизводится командой:

```sh
cargo run --release -p luna-user-session --example render-alpha -- "$PWD" "$PWD/target/luna-alpha-design-20261013/preview"
cp target/luna-alpha-design-20261013/preview/rings-uefi.xrgb components/boot/assets/rings-uefi.xrgb
```

Кадры `preview/native-*.png` — локальная проверка renderer; доказательства
загрузки и действий хранятся отдельно в `target/canonical-workbench/evidence/`.

## Реализация

- `renderer.rs`: ночное небо на весь экран, форма слева, русские подписи,
  текст ошибки, Adwaita Sans из закреплённых входных ресурсов, палитра Alpha.
  Область встроенной кнопки входа исключена из области фокуса поля.
- `rings.rs`: радиусы, сечение, фаски, нормали, три оси и периоды 12/17/23 с
  перенесены из прототипа. Исходная фактура смешивается по трём проекциям;
  рассчитываются глубина, мягкие тени и три слоя свечения. Каждый из 48 циклов
  имеет отдельное начало и период 5–10 с, обновляемый на границе косинуса.
  Программный renderer использует существующие png/fontdue и framebuffer,
  не требует EGL до запуска compositor и не хранит бесконечную анимацию кадрами.
  Предрассчитанные кадры камня возможны, но случайность рун потребовала бы
  отдельного динамического слоя, проверки глубины и большого набора ресурсов.
  Короткое видео не воспроизводит независимые новые периоды; поэтому выбран
  один нативный renderer без нового поставщика графики.
- `resources/alpha/`: конфигурации niri, Noctalia 5.2.0 и Ghostty. Пользовательская
  палитра Noctalia содержит также обязательную terminal-палитру.
  Adwaita Sans включён в системные ресурсы и GUI-бандлы; Nerd Mono остаётся
  явно выбранным шрифтом терминала.
- Files: плотные поверхности, выделение строк, компактная панель настоящих
  операций и навигация по реальному HOME. Файловый движок и IPC сохранены.
  Цвет подписи каждой строки задан явно: тема GTK не может сделать текст
  невыбранных файлов чёрным на тёмном фоне. Недоступные значки заменены подписями.
- Сборщик включает фон, фактуру и шрифт в System Image, начальные настройки
  рабочего стола — в DATA. Тема Ghostty является частью проверяемого бандла.

## Отличия от HTML

Рабочий стол использует настоящие прокручиваемые колонки niri. Меню, быстрые
настройки и системные настройки сохраняют поддерживаемую композицию Noctalia;
её исходники не изменены. Шрифт входа — Adwaita Sans; размеры увеличены для
читаемости. Программные кольца пока без сглаживания WebGL, геометрия и движение
совпадают с моделью. Отдельный экран блокировки и приложение просмотра колец
не добавлены. Сеть, батарея, аудио и файлы показывают состояние гостевой системы;
оборудование, отсутствующее в QEMU, не заменяется данными прототипа.
Каталог Alpha показывает установленные и разрешённые Files и Terminal;
демонстрационные Firefox и другие пункты HTML в каталог не добавляются.
Часть стандартных подписей и диалогов GTK/Files сохраняет прежнюю локализацию
и композицию. Аппаратные действия Wi-Fi/Bluetooth/яркости на ноутбуке отдельно
не проверялись; открытие панели настроек не доказывает работу отсутствующего устройства.
