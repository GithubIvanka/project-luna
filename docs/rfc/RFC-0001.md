# RFC-0001 — Luna Core Architecture

**Status:** Draft  
**Type:** Architecture

## Purpose

RFC-0001 will formalize the foundational Luna architecture after the Architecture Source of Truth has stabilized.

It is expected to cover:

- project principles;
- EFI / SYSTEM / DATA / SWAP separation;
- immutable System Images;
- kernel separation;
- boot and recovery boundaries;
- logical root and DATA separation;
- update and fallback invariants.

This draft intentionally does not introduce new architecture decisions. Accepted decisions are recorded in `docs/decisions/` and `docs/ARCHITECTURE.md`.
