# RFC-0002 — Bundle Format v1

**Status:** Planned / Draft  
**Type:** Format

## Purpose

RFC-0002 will formally specify Luna's `.lbp` Bundle Format v1.

It is expected to define:

- bundle structure;
- metadata;
- manifest;
- payload;
- identifiers;
- dependencies;
- architecture/platform compatibility;
- installation;
- update;
- removal;
- integrity verification;
- optional signatures if later accepted.

System Images are explicitly outside this RFC: a Luna System Image remains a SquashFS image and is not an `.lbp` bundle.

This draft intentionally does not introduce new architecture decisions.
