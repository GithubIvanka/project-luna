# Project Luna

## Summary

Project Luna is a modern immutable operating system built on the Linux kernel.

The project prioritizes simplicity, predictability and maintainability over feature count.

## Motivation

Traditional Linux distributions carry decades of historical design decisions.

Project Luna attempts to rethink the operating system architecture while preserving the strengths of the Linux kernel.

## Goals

- Immutable operating system
- Human-readable filesystem
- Self-contained applications
- Atomic updates
- Modern desktop
- Rust-first development

## Non-Goals

Project Luna is not intended to become another traditional Linux distribution.

The project does not attempt to maintain compatibility with every historical Unix convention.

## Philosophy

Architecture comes before implementation.

Documentation comes before architecture.

Simplicity comes before features.
