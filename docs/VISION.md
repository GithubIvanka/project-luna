# Vision

> **Simple by design. Reliable by default.**

Project Luna exists because modern operating systems have become increasingly complex.

Many Linux distributions still inherit design decisions made decades ago. While these decisions were reasonable at the time, they often make modern systems harder to understand, maintain and evolve.

Project Luna aims to build a clean and modern operating system while remaining powered by the Linux kernel.

The project is not focused on adding more features.

Instead, it focuses on improving architecture, readability, maintainability and reliability.

## Core Ideas

- Immutable operating system
- Simple filesystem layout
- Self-contained applications
- Atomic updates
- Clear architecture
- Human-readable configuration
- Modern desktop experience
- Rust-first development

## Design Philosophy

Complexity is a cost.

Every new feature must justify its existence.

If a feature makes the system significantly more complicated without providing proportional value, it probably does not belong in Luna.

Project Luna is designed around clarity rather than tradition.

Every architectural decision should answer two questions:

- Why does this exist?
- Can it be made simpler?

If the answer to the second question is "yes", the design should be reconsidered.

Project Luna is not an attempt to replace Linux.

It is an attempt to build a better operating system on top of the Linux kernel.
