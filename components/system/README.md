# System Applications

`components/system/` содержит Luna-owned приложения и административные инструменты, которые используют core, но не являются его фундаментом.

Сейчас:

- `luna-app-manager`
- `luna-cli`

Будущие system utilities добавляются сюда только когда их lifecycle и responsibility действительно относятся к системному application layer.
